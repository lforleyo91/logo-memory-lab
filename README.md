# Logo Memory Lab — The Designer's Edition

A QR-join Mandela Effect icebreaker for designers. The game features 15 left/right logo-memory rounds, a host/projector screen, player voting, answer reveals, explanations and a live leaderboard.

## Run locally
Requires Node.js 18 or newer.

```sh
npm install
npm start
```

Open http://localhost:3000. Players join at `/?mode=play&room=LAB26`.

## Deploy on Render
Use a Node Web Service. Build command: `npm install`. Start command: `npm start`. Free services may sleep while idle; open the host page early before your event. Room state and scores are held in memory, so keep the service running during play.

## Quiz topics
Figma, DBS, POSB, Old Chang Kee, SMRT, Apple, Claude, Pikachu, Monopoly, Starbucks, KFC, Looney Tunes, KitKat, Fruit of the Loom and Froot Loops.

Note: quiz marks are simplified illustrations, not official brand artwork.
